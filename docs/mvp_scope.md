# MVP Scope

## Назначение документа

Документ фиксирует границы MVP (Minimum Viable Product) проекта AI Fashion Wardrobe.

Любая новая функциональность оценивается относительно данного документа. Если функция не относится к описанному пользовательскому сценарию, она не входит в MVP и рассматривается только после завершения первой версии.

---

# Цель MVP

Создать минимально работоспособную версию AI-приложения, которое позволяет пользователю:

- загрузить фотографию предмета одежды;
- автоматически распознать характеристики вещи;
- проверить и при необходимости исправить результаты распознавания;
- сохранить вещь в цифровом гардеробе;
- выбрать контекст для подбора образа;
- получить три готовых варианта образов исключительно из собственного гардероба;
- поставить оценку полученным рекомендациям.

---

# Основной пользовательский сценарий

```
Загрузка фотографии

        ↓

AI распознаёт характеристики вещи

        ↓

Пользователь проверяет и при необходимости исправляет данные

        ↓

Вещь сохраняется в цифровом гардеробе

        ↓

Пользователь выбирает контекст
(повод, сезон, стиль)

        ↓

Система генерирует три варианта образов

        ↓

Для каждого образа отображается объяснение выбора

        ↓

Пользователь ставит 👍 или 👎
```

---

# Функции, входящие в MVP

Обязательные функции первой версии:

1. Загрузка фотографии одежды.
2. Автоматическое распознавание характеристик вещи (AI Vision).
3. Возможность ручного редактирования результатов распознавания.
4. Сохранение вещи в цифровом гардеробе.
5. Выбор контекста для генерации образа.
6. Подбор трёх различных образов из вещей пользователя.
7. Объяснение выбора каждого образа.
8. Возможность поставить лайк или дизлайк рекомендации.

---

# Что НЕ входит в MVP

В первую версию не входят:

- рекомендации покупки новых вещей;
- интеграции с маркетплейсами;
- автоматический анализ модных трендов;
- виртуальная примерка (AR);
- распознавание размеров одежды;
- подбор аксессуаров;
- подбор обуви, косметики или причёсок;
- генерация новых вещей;
- календарь образов;
- мобильное приложение;
- социальные функции;
- автоматическое обучение моделей на пользовательских данных.

---

# Принципы MVP

При разработке первой версии соблюдаются следующие принципы:

- рекомендации строятся только из вещей пользователя;
- AI Vision отвечает только за распознавание фотографии;
- пользователь всегда может исправить ошибки AI;
- подбор образов выполняется только после сохранения вещи в гардероб;
- каждая рекомендация сопровождается объяснением;
- обратная связь пользователя сохраняется для последующего анализа качества рекомендаций.

---

# Критерий готовности MVP

MVP считается завершённым, если пользователь может самостоятельно пройти полный сценарий от загрузки фотографии одежды до получения трёх рекомендаций образов и оценки результата без участия разработчика.
