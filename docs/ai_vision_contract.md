# AI Vision Contract

## Назначение

AI Vision анализирует фотографию одной вещи и возвращает её визуально определяемые характеристики в формате JSON.

AI Vision является первым модулем в цепочке:

```text
AI Vision → Fashion Engine → AI Stylist → Validator
```

AI Vision не подбирает образы и не принимает fashion-решения.

## Вход

Одно изображение одной вещи в формате JPG, JPEG или PNG.

Желательно, чтобы:

* вещь была видна целиком;
* на фотографии была одна вещь;
* изображение было достаточно резким;
* цвет не был сильно искажён освещением.

## Выход

AI Vision возвращает JSON, совместимый с доменными моделями и справочниками проекта.

Пример:

```json
{
  "schema_version": "1.0",
  "status": "success",
  "item": {
    "category": "top",
    "subcategory": "t_shirt",
    "primary_color": "white",
    "secondary_colors": [],
    "pattern": "solid",
    "material": null,
    "fit": "regular",
    "sleeve_length": "short",
    "formality": "casual",
    "seasons": ["summer"]
  },
  "uncertain_fields": [
    "material"
  ],
  "image_quality_issues": []
}
```

Точные поля и значения должны соответствовать существующим Pydantic-моделям и JSON-справочникам проекта.

## Основные правила

AI Vision должен:

* использовать только значения из справочников;
* возвращать `null`, если характеристику нельзя определить;
* не придумывать материал, бренд, размер и другие невидимые характеристики;
* отмечать сомнительные поля в `uncertain_fields`;
* возвращать только JSON без дополнительного текста;
* анализировать только одну вещь.

AI Vision не должен:

* создавать `item_id`;
* сохранять вещь в гардероб;
* подбирать образы;
* оценивать сочетаемость вещей;
* выполнять функции Fashion Engine или AI Stylist.

## Статусы

Допустимые значения поля `status`:

* `success` — основные характеристики распознаны;
* `partial` — вещь распознана, но часть полей неизвестна;
* `rejected` — изображение нельзя корректно обработать.

## Неопределённые характеристики

Если характеристику нельзя надёжно определить по фотографии, модель должна вернуть `null`.

Это особенно важно для:

* материала;
* состава ткани;
* посадки;
* сезонности;
* размера;
* бренда.

Корректный `null` лучше, чем правдоподобная галлюцинация.

## Связь с WardrobeItem

Результат AI Vision не является готовой вещью гардероба.

Поток данных:

```text
Фотография
    ↓
AIRecognitionResult
    ↓
Программная валидация
    ↓
Корректировка пользователем
    ↓
WardrobeItem
```

`WardrobeItem` создаётся только после проверки и подтверждения пользователем.

## Валидация

Ответ AI Vision должен пройти программную проверку:

* JSON корректно парсится;
* обязательные поля присутствуют;
* значения существуют в справочниках;
* отсутствуют неизвестные поля;
* отсутствуют выдуманные идентификаторы;
* неприменимые характеристики не заполнены случайными значениями.

## Версионирование

JSON-схема и промпт должны иметь версии.

Пример:

```text
schema_version: 1.0
prompt_version: vision_v1
```

Промпты хранятся в Git как часть кода.
